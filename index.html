Definitions
RUN
RUN means since the run began. A figure with no period is today's.
Start Bal
The balance at today's open: the $10,000 the run began with, plus every earlier day's Net. It does not move during the day.
Init BP
Today's buying power: Start Bal times the run's leverage, set at the open. It does not move during the day.
Real
The day's price result on trades closed that day. No fee is in it.
Unreal
Open positions at the latest 5-second mark: their price result so far, before any fee. Includes stale prices, and values a never-priced symbol at its entry, so it will not tie exactly to the Unreal $ column in the model drill-down.
P&L
The day's price result: trades closed that day plus, for the latest day, open positions at their last price. No fee is in it.
Token $
The day's token spend on this model's calls. Zero or negative.
Comm $
The day's broker commission: a charge per share on every entry and every exit, booked when the trade closes. Zero or negative. "not booked" means the day's trades closed before commission and ECN booking began.
ECN $
The day's ECN: every route charge (negative) and rebate (positive), summed. An order that rested on the book earns the route's rebate; one that took the far touch pays the route's charge, if it has one. Booked when the trade closes, both legs at once.
Net
P&L + Token $ + Comm $ + ECN $: the day's change in equity. An open position's commission and ECN are booked when it closes, so until then Net leaves them out.
RUN P&L
The price result since the run began: closed trades plus open positions. No fee is in it. The run's token spend, commission and ECN are in Equity; today's are also in Net.
RUN Token $/Trade
An average: all token spend since the run began, divided by the run's count in Trades. Zero or negative, like Token $. It includes spend on decisions that opened no trade.
DAY/RUN Trades
Closed trades: today's count, then the run's, as in 12/189. The column sorts on the run's count.
RUN Win%
The share of the run's closed trades whose price result is above zero. A flat trade counts as a trade, not as a win.
Equity
Start Bal + Net: the balance now, after token spend, commission and ECN. Its colour compares it with the $10,000 the run began with.
